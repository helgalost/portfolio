# Портфолио Ольги Чуманевой

Статический сайт без сборки: `index.html` + `assets/` + `img/`. Публикуется через GitHub Pages.

## Структура

```
index.html            разметка всех разделов
assets/css/style.css  стили (цвета обеих тем — в начале файла, блок «Токены»)
assets/js/works.js    список работ: названия, категории, описания
assets/js/main.js     поведение: тема, галерея, лайтбокс, раскрытие кейсов
assets/fonts/         шрифты Dela Gothic One и Golos Text (лежат локально)
img/works/            работы в полном размере (до 2000 px)
img/works/thumb/      превью работ для сетки (.webp, 720 px)
img/certs/            сертификаты (+ thumb/)
img/cases/            картинки кейсов
img/me.webm, me.mp4   видео на первом экране
```

## Как добавить работу

1. Положите файл в `img/works/`, например `work-53.jpg`. Желательно не больше 2000 px по длинной стороне.
2. Сделайте превью шириной ~720 px в формате WebP и положите в `img/works/thumb/work-53.webp`.
3. Добавьте строку в `assets/js/works.js` в массив `WORKS`:

   ```js
   {"n": 53, "src": "img/works/work-53.jpg", "thumb": "img/works/thumb/work-53.webp", "w": 720, "h": 1080,
    "cat": "photo", "title": "Название", "desc": "Описание, которое видно при открытии."}
   ```

   `w` и `h` — размеры превью, `cat` — одна из категорий: `photo`, `product`, `ad`, `web`.
4. Чтобы работа попала в шесть избранных, впишите её номер в `FEATURED` в начале того же файла.
